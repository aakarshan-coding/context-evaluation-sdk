# Ridgeline Gravel SL

The Gravel SL is a drop-bar bike for mixed surfaces: dirt roads, light singletrack, and pavement between them.

The frame is carbon, and the wheels come set up tubeless from the shop. It clears 700 x 50c tires or 650b x 2.1 inch tires. It ships with 700 x 42c tires. There are mounts for three bottles, a top-tube bag, and fenders, but no rear rack mounts.

The standard build uses a Shimano GRX 2x12 drivetrain and weighs 8.9 kg (19.6 lb) in size 54. The price is $2,749. A GRX 1x12 build with a 40t chainring and 10-51t cassette is also available for $2,649.

Sizes are 50, 52, 54, 56, 58, and 61 cm. The 50 cm size uses 650b wheels only.
